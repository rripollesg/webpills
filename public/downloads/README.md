# Descargas APK

Coloca aquí los APK de instalación directa para Android.

## Estructura

```
downloads/
├── pills/
│   └── pills.apk          ← app móvil Pills (Android)
└── pills-tv/
    └── pills-tv.apk       ← companion Pills TV (Android TV / Fire TV)
```

## App Store y Google Play

Los enlaces a las tiendas se configuran en `src/config/downloads.ts` (`storeUrls.appStore` y `storeUrls.googlePlay`).
